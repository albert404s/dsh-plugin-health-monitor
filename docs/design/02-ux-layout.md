## 0. 结论先行：实现者必须记住的 10 条

1. **首页顺序调整**：导航/状态 → 首屏 + 四象限 → 仪器指标 → 榜单 + 关注 → 插件索引 → 计算说明。当前 `PluginExplorer` 在榜单之前，需下移到榜单与关注之后。
2. **首屏只留两个重心**：H1 文案区与四象限面板。删除首屏 meta 行（更新时间 / 插件数 / 高风险 / 来源降级），这些信息各归其位。
3. **首屏只保留一个实心主按钮**“浏览全部插件”；“四象限完整视图”“评分方法”降为文字链接，避免三个同等权重的动作。
4. **导航从 4 项增至 5 项**：总览 / 四象限 / 插件索引 / 对比 / 方法。索引区下移后，用导航保证“找具体插件”的可达性。
5. **首页只保留两块 `.panel`**：四象限、插件索引。指标用全宽 `DataBand`，榜单用分隔线列表，避免同尺寸白卡片连续堆叠。
6. **全站时间信息只保留两种语义**：导航里的**相对时间**（全局状态），数据面底部的**绝对快照**（就近证据）。异常才出现横幅，且同一屏最多一条。
7. **“相对评价 / 缺失不记 0 / 不补造趋势”只在两处出现**：首页方法条、方法页。从指标脚注、首屏、页脚、图表图例中删除。
8. **风险色与品牌红分离**：品牌红只用于交互与当前项；风险必须有“图标 + 文字 + 非红色线索”（描边、斜纹、虚线），不能只靠颜色。
9. **中文可读性硬约束**：12px 只做标签；正文 ≥13px、行高 ≥1.6；正文单行 ≤34 个汉字；数字一律等宽对齐。
10. **图表高度按 390/768/1024/1280 四档固定**（见 §7.2）；长插件名表格截断、卡片 2 行、详情 H1 可断行；任何宽度都不允许页面级横向滚动。

## 1. 信息架构原则

### 1.1 用户任务顺序

页面回答问题的顺序必须与用户的决策顺序一致：

1. **这是什么、是否可信**（标题、一句话、快照时间、来源）
2. **整体现在怎么样**（四象限 + 5 个仪器读数）
3. **谁最突出、谁值得注意**（人气榜 / 维护榜 / 关注 / 变化）
4. **具体是谁、是否符合我的需要**（搜索、筛选、列表）
5. **这些数字怎么来的、能信到什么程度**（方法、局限、缺失）

首页六区块就是这五步的物理顺序；任何新增模块都必须回答“它属于哪一步”，否则不进首页。

### 1.2 一条信息只出现一次

同一事实只允许有一个“主位置”，其他位置只能以不同粒度复述：

- 更新时间：导航常驻相对时间；每个数据区域只设一个“快照落点”显示绝对时间（首页＝指标带与索引分页，详情＝评分带，对比＝选择区，方法＝meta chip）。图表、榜单不重复绝对时间。
- 插件数：指标带 + 索引计数；首屏 CTA 不写数字。
- 高风险数：指标带（可点击）+ 关注列表；首屏不写。
- 方法声明：首页方法条 + 方法页；页脚只留一句法律性说明。

### 1.3 每个区块一个视觉重心

| 区块 | 唯一主角 | 不允许并列的主角 |
|---|---|---|
| 首屏 | 四象限图 | 大段介绍、三个按钮、指标数字 |
| 指标带 | 5 个读数 | 图标、说明段落、脚注 |
| 榜单 | 排名与分值 | 头像、长描述、标签云 |
| 索引 | 搜索框 + 结果行 | 营销文案、图表 |
| 方法条 | 一句边界声明 | 完整公式、表格 |

## 2. 全局框架

### 2.1 页面骨架

```
<a class="skip-link">跳至主要内容</a>
<Header />                         sticky，64px（<768 为 56px）
<DataNotices />                    仅异常时出现，不 sticky，滚动离开
<main id="main-content" tabindex="-1">
  <页面内容 />
</main>
<Footer />
```

- `main` 在路由切换后接收焦点（`tabindex="-1"`），并更新 `document.title`；这是 SPA 的可达性基线。
- `DataNotices` 永远是**页面级、单条**；不允许在区块内部再复制同样文案。
- `Footer` 不承担状态播报；只保留方法版本、数据来源、源码入口、绝对快照。

### 2.2 容器与栅格

| 令牌 | ≥1280 | 768–1279 | <768 | 说明 |
|---|---|---|---|---|
| `--shell` | 1400px | 1400px | 100% | 全局最大宽度 |
| 左右内边距 | 32px | 24px | 16px | 内容宽 1336 / 720 / 358（以 1440/768/390 计） |
| 主栅格 | 12 栏 / 24px gutter | 12 栏 / 16px gutter | 单列 / 12px 间距 | 区块内部用 span 表达 |
| 区块间距 | 64px | 48px | 48px | `mt-16 / mt-12` |
| 面板内边距 | 20–24px | 16–20px | 16px | 表格行内边距单独定义 |
| 边框 | 1px | 1px | 1px | 只用 `line` / `line-hairline` |
| 圆角 | 面板 6px、控件 6px、chip 4px | 同左 | 同左 | BRIEF 要求 0–6px；当前 `rounded-panel` 为 8px，需在 01 中改为 6px |
| 阴影 | 仅浮层 | 仅浮层 | 仅浮层 | 面板不用 `shadow-panel`，改为 1px 边框 + 结构线 |

**断点定义**（使用 Tailwind 默认值，不新增）：

| 名称 | 视口 | 用途 |
|---|---|---|
| Mobile | 390（基准） | 单列、卡片、折叠筛选 |
| Tablet | 768（`md`） | 双列、指标 6 栏技巧、卡片双列 |
| Desktop | 1024（`lg`） | 表格、四象限双栏、对比表 |
| Wide | 1280（`xl`） | 首页 8+4、详情右栏、四象限侧栏 |
| Target | 1440 | 设计验收宽度 |

### 2.3 导航（Header）

**结构**：左品牌 → 主导航 → 右状态区。

| 区域 | ≥1024 | 768–1023 | <768 |
|---|---|---|---|
| 品牌 | 图标 32 + 中文名 + 英文副题 | 图标 + 中文名 | 图标 + “DSH 健康看板” |
| 导航 | 5 项全部显示 | 5 项显示（字号 13） | 汉堡菜单 |
| 状态胶囊 | 圆点 + 相对时间 + 状态词 | 同左 | 圆点 + 极短时间（“12 分”） |
| 刷新 | 图标按钮 40 | 图标按钮 40 | 收进状态浮层，不占头部 |
| GitHub | 图标按钮（≥1280） | 隐藏 | 收进菜单 |
| 菜单 | 无 | 无 | 44×44 |

**导航项**：

| 顺序 | 标签 | 目标 | 激活规则 |
|---|---|---|---|
| 1 | 总览 | `/` | 仅首页 |
| 2 | 四象限 | `/quadrant` | 路由匹配 |
| 3 | 插件索引 | `/#all-plugins` | 不参与路由激活；用锚点滚动 |
| 4 | 对比 | `/compare` | 路由匹配 |
| 5 | 方法 | `/method` | 路由匹配 |

- 激活态：文字 `content-primary` + 底部 2px `accent` 下划线（左右各留 12px 内缩），不加背景块；红色只出现在这一条下划线与状态点，避免头部泛红。
- hover：文字转 `content-primary`，无位移、无阴影。
- focus-visible：2px `accent` 外环，offset 2；导航项高度占满头部，保证 44px 命中区。
- 移动端菜单：`max-height: calc(100dvh - 56px)`，内部滚动；每项 48px；当前项用左侧 2px 红条 + `accent-soft` 背景，不用整块红。
- 菜单底部只保留“数据来源”一行，删除当前重复的三行来源/时间小字（移入状态浮层）。

**状态胶囊**：

- 默认（正常）：`● 12 分钟前`；`title` 为精确时间。
- 过期（>8h）：`● 8 小时前 · 可能已过期`（桌面）；移动端 `● 8 小时前`，浮层内写全。
- 部分/失败：`● 部分数据` / `● 更新失败`，颜色用 `warning` / `danger`，同时保留文字。
- 点击打开 320px 浮层（桌面右对齐；移动端全宽抽屉式，`max-width: calc(100vw - 32px)`），内容：
  1. `快照 2026-10-20 11:25 · 12 分钟前`
  2. `GitHub 正常 / npm 正常 / OSV 正常`（3 行，带状态点）
  3. `更新频率：每 6 小时`（来自 `status.nextRunHint`，不要伪造“下次更新时间”）
  4. `重新加载` 按钮 + `数据方法与更新机制` 链接
- 浮层键盘：Enter/Space 打开，Esc 关闭，焦点困在浮层内，关闭后回到胶囊。

### 2.4 页面头模板

所有一级页面共用同一节奏，避免每页各写一套：

```
eyebrow（12px mono）         [可选：右侧统计/操作]
H1（48/40/32）
lead（16/17px，≤ 2 行，≤ 34 汉字/行）
meta 行（可选：快照、来源、方法版本）
```

- 页面头下方 24px 进入首个数据模块；不再放装饰性大图。
- H1 字数控制在 18 个汉字以内；超长标题拆为 H1 + lead。
- 操作按钮与页面头基线对齐；<1024 时换行到 lead 下方，主按钮在左。

### 2.5 页脚

- ≥768：三栏 `1.4fr / 1fr / 1fr`；<768 单列。
- 内容：品牌 + 一句定位 + 来源；浏览链接；方法版本 + 快照时间 + GitHub。
- 删除与首页方法条重复的长免责声明；页脚只保留一句：“独立分析站，不构成质量、安全或兼容性背书。”
- 快照时间用绝对时间（便于引用），与导航的相对时间形成互补，不算重复。

### 2.6 锚点与滚动偏移

当前 `scroll-mt-24`（96px）在横幅出现时会遮住标题。统一定义：

```css
:root {
  --header-h: 64px;   /* <768: 56px */
  --notice-h: 0px;    /* DataNotices 渲染时由组件写入实际高度 */
}
[id] { scroll-margin-top: calc(var(--header-h) + var(--notice-h) + 16px); }
```

- 所有 `#all-plugins`、`#method-note`、`#risk-evidence` 等锚点复用该变量。
- 对比页表头 sticky 的 `top` 同样使用该表达式，不再写死 `top-16`。
- 同一路径 + 同一 hash 的导航（如首页内点“完整榜单”再次指向 `#all-plugins`）也要重新滚动：`ScrollToTop` 需同时监听 `search`，或在点击时显式 `scrollIntoView`。

| 区域 | 首屏注意力 | 依据 |
|---|---|---|
| 四象限面板 | 55% | 769×580，唯一的大面积面 |

### 3.1 区块 1：导航与状态

见 §2.3。首页额外规则：

- 不再渲染首屏 meta 行；更新、插件数、高风险、来源状态分别由导航、指标带、关注区承担。
- 首页不显示“v0.1.0”之类的版本号；版本只在方法页与页脚出现。
- 数据来源不在首页头部展开；状态浮层与方法页是唯一入口。

### 3.2 区块 2：首屏 + 四象限

#### 左栏（5 栏，543px @1440）

| 元素 | 规格 | 文案/规则 |
|---|---|---|
| eyebrow | 12px mono，`0.04em`，`content-muted` | `01 / OVERVIEW · 独立观察`（英文编号 + 中文短语；点阵/等宽只用于此） |

#### 右栏：四象限面板（7 栏，769px @1440）

面板是首屏唯一 `.panel`，结构固定为四段：

| 段 | 高度 | 内容 | 视觉 |
|---|---|---|---|
| 面板头 | 56px | 左：`人气 × 维护健康度`（18px 600）+ 一行 12px 说明；右：`18 / 20`（mono 20px）+ “已定位插件”；`完整视图 →` 链接 | 1px 底边；不加红色 |
| 分区计数 | 40px | 4 组：`● 热门且健康 6` / `● 小众稳健 5` / `● 待维护 4` / `● 低活跃 3`（计数为示例，实际按快照计算） | 12px；圆点 6px；数字 mono；一行排布 |
| 图表 | 440px | `QuadrantChart`，`showLabels={false}`、`showLegend={false}`、`showUnpositioned={false}` | 固定 0–100 轴；阈值虚线中性灰；无标题遮挡 |
| 面板脚 | 44px | `18/20 已定位 · 阈值 X 50 / Y 60` + InfoHint + `悬停查看 · 点击进入详情` | 12px muted；移动端换行并追加“第一次点按看概要，再次点按进详情”；**不写时间戳**（由吸顶导航的相对时间 + 指标带的绝对快照承担） |

- **视觉重心（主角）**：图表占面板面积 76%，是首屏最大的连续面。面板头、计数、脚部都是 12–18px 的辅助信息，不与图争。
- **不重复**：分区计数与图表图例二选一。首页关闭图例，只在计数行展示；`QuadrantChart` 的 `showLegend` 传 `false`。
- **不重复**：`已定位 18/20` 只在面板头出现一次；不再在图例末尾写“共定位 18/20”。
- **阈值说明**：只在面板脚出现一次，配 InfoHint；删除“不是行业标准”的长句，方法页承担完整解释。
- 面板顶部加 2px×64px 的**墨色刻度条**（装饰，`aria-hidden`），与红色强调区分；不要用红色顶边。
- 图表空态：`当前没有可定位插件` + `查看未定位原因`（链接到四象限页的未定位清单 `/quadrant`）；不要画空坐标系冒充数据。
- 图表加载态：保留面板框与标题，画 4 个象限的浅色分区与坐标轴，中央写“正在读取快照…”，不画假点。

#### 首屏五秒检验（必须通过）

在 390×844 下，首屏应同时出现：

1. H1 与一句说明（知道“这是什么”）；
2. 四象限面板的标题与至少 2/3 图表区域（知道“核心内容”）；

2. **区块头**：`SectionHeading` 只用一个 H2；description 最多 2 行；一个区块最多一个右侧操作。
3. **面板**：一个数据模块一个 `.panel`；面板内不再套 `.panel`；图表、表格、列表共享同一套边框与头部高度（48/56）。
4. **列表 vs 卡片**：≥1024 用表格/分隔线列表；768–1023 用双列卡片；<768 单列卡片。不要在同一屏混用两种列表表达。
5. **链接**：正文链接用下划线（`underline-offset-4`），hover 变 `accent`；不要在整段文字上做“卡片链接”。
6. **按钮**：一个视图一个主按钮；次要按钮最多两个；其余用文字链接。
7. **空态**：标题 + 一句原因 + 一个动作；高度 ≥240；不做插画。
8. **错误**：说明“发生了什么 + 现在展示什么 + 下一步”；保留上次成功数据；不整页白屏。
9. **页脚**：三栏；不重复方法条；快照绝对时间只在这里和方法页出现。
10. **动效**：页面淡入 120ms；图表 200ms；`prefers-reduced-motion` 下全部关闭；不做视差、不做自动轮播。

## 5. 数据状态与就近提示

本节统一约定数据更新时间、采集状态、缺失、风险与时效提示的落点：全局状态在导航，异常在横幅，证据在数据面，解释在方法页。任何状态都不得只靠颜色表达。

### 5.1 状态阶梯

| 级别 | 判定 | Header | 横幅 | 数据面就近提示 |
|---|---|---|---|---|
| L0 正常 | `outcome=success`、3 个来源 `ok`、快照 ≤8h | 绿点 + `12 分钟前` | 无 | 各页快照落点显示绝对时间，中性色 |
| L1 部分 | `outcome=partial` 或任一来源 `partial/failed`，快照 ≤8h | 黄点 + `部分数据` | 黄底单条：`部分数据源降级，缺失项不会记为 0。` + 来源名 + `数据状态 →` | 仅受影响指标格加 `部分` chip 或 `—`；其他格不动 |
| L2 过期 | 快照 >8h（`isDataStale`） | 黄点 + `8 小时前 · 可能已过期` | 黄底：`数据可能已过期。当前展示 {绝对时间} 的快照。` + `查看更新机制` + `重新加载` | 各页快照落点后缀 `· 可能已过期`（首页指标带、索引分页行；详情评分带；对比选择区） |
| L3 失败 | `outcome=failed` | 红点 + `更新失败` | 红底：`最近一次更新失败。继续展示上次成功快照。` + 时间 + 重试 | 快照落点改为 `上次成功快照 {时间}`；不隐藏数据 |
| L4 刷新失败 | 已有数据，刷新请求失败 | 保持原状态 | 黄底：`刷新失败，继续展示上次成功加载的快照。` + 错误摘要 + `重试` | 不改快照落点时间；不新增局部提示 |
| L5 无数据 | 首次加载失败 | 红点 + `数据不可用` | 整页 `ErrorState` | 无数据面 |

- 横幅最多一条；出现 L3 时不再叠 L1 文案，来源失败写进同一行。
- 状态颜色必须同时有文字；圆点只是辅助。
- 所有时间显示 `Asia/Shanghai`；相对时间用于导航，绝对时间用于数据面。

### 5.2 各页面“就近呈现”矩阵

| 页面 / 数据面 | 绝对时间 | 采集状态 | 缺失 | 风险 | 时效 |
|---|---|---|---|---|---|
| 首页 · 四象限 | 无（吸顶导航显示相对时间；绝对快照见指标带） | 无（状态见指标带出处行） | 未定位 details + `18/20` | tooltip + 风险图例（颜色外有文字） | 由指标带出处行统一承担 |
| 首页 · 指标带 | 出处行 `快照 11:25 · 12 分钟前` | 出处行右侧 `3 个来源正常` / `1 个来源降级` | `—` + `等待快照` | 高风险格数字 + `title` | 出处行后缀 `· 可能已过期` |
| 首页 · 榜单 | 行内相对时间 | 无 | `—` + `信息不足` | 风险徽章 | 不重复 |
| 首页 · 索引 | 分页行 `快照 11:25` | 无 | 覆盖列 `5/7 域` | 风险列 | 快照后缀 |
| 详情 · 评分带 | 带右上 `快照 11:25` | 右侧来源入口 | 每格缺失说明 | 风险格 + 徽章 | 带内后缀 |
| 详情 · 趋势 | `n 个真实快照 · 跨度 x 小时` | 无 | 空态说明 + 不画线 | 无 | `历史不足` 提示 |
| 详情 · 来源 | 每行 source time | 每行状态 badge | 每行 `—` + 原因 | 无 | 表尾快照 |
| 对比 | 选择区 `同一快照 11:25` | 无 | `不可比` | 风险行 | 完整度提示 |
| 方法 | meta chip `当前快照` | 流水线章节 | 章节说明 | 风险章节 | 保留策略 |

**就近原则**：任何数字下方或同一面板内，至少能看到“它是什么时候的”；任何 `—` 旁边，至少能看到“为什么没有”。

### 5.3 文案模板

| 场景 | 文案 |

| 刷新中 | `正在重新加载快照…` |
| 加载失败 | `数据快照无法加载` + 具体错误 + `重新加载` + `查看数据方法与更新机制` |

### 5.4 缺失 / 风险 / 时效的硬规则

1. 缺失不写 0；用 `—`、`信息不足`、`不可比` 三种之一，并给出原因。
2. 不把“未检查”写成“安全”；不把“无公开记录”写成“无漏洞”。
3. 风险等级必须有文字标签；高风险还必须有一个非颜色线索（粗描边/斜纹/图标）。
4. 时效提示只在“过期”时出现；正常状态不要写“数据可能不是最新”这类无信息文案。
5. 历史不足不补点、不插值、不画虚线趋势；只用文字 + 当前值。
6. 缺失原因优先放详情页；列表只在有空间时放 12px 一行，否则用 `title` + 详情链接。
7. 百分比与分数都保留 1 位小数；覆盖率用整数；计数用 `formatCompact`，`title` 给精确值。

## 6. 交互与状态

### 6.0 控制状态总矩阵

> 每个控件都必须定义以下 7 类状态；“局部/页面级”指错误由谁承担。数据加载失败统一由页面级 `ErrorState` 承担，控件自身不显示半张结果。

| 控件 | hover | focus | active / selected | disabled | empty | loading | error |
|---|---|---|---|---|---|---|---|
| 搜索框 | 边框 `content-muted` | `accent` 边框 + 3px soft 环 | 输入中；清除按钮出现 | 数据加载中禁用 | 无结果 → 空态 + query | 输入框禁用 + 骨架列表 | 不适用（本地筛选） |
| 筛选 select | 边框 `content-muted` | `accent` 边框 + 环 | 非默认值 + 可移除 chip | 加载中禁用 | 0 结果仍可修改，不自动重置 | 禁用 + `aria-busy` | 页面级 |
| 排序（表头/下拉） | 表头文字转主色；箭头显现 | 2px 环（表头用 inset） | `aria-sort` + 箭头方向 | 无（全部可排） | 无 | 表头/下拉禁用 | 页面级 |
| 分页 | 页码背景 `surface-subtle` | 2px 环 | 当前页实心 `accent` | 首/末页 35% 透明 | 结果 0 时不渲染分页 | 禁用 + 骨架行 | 页面级 |
| 图表 | 气泡放大 + tooltip | 图表本身不聚焦；列表路径可聚焦 | 触屏选中气泡 + tooltip | 无可定位插件时不渲染交互 | 中央文案 + 未定位链接 | 轴/分区保留 + “正在读取快照…” | 面板内 notice + 重试 |
| 对比入口 | 按钮/交换按钮 hover 边框 | 2px 环 | 交换/选择后 URL 更新 | 同侧已选 option；少于 2 个插件 | 示例对 / 少于 2 个空态 | 选择器禁用 + 骨架卡 | 页面级 |
| 刷新 | 边框 `content-muted` | 2px 环 | 点击后立即进入 loading，不改变尺寸 | 加载中禁用 | 无数据时仍可重试 | 旋转 + `aria-live` | 横幅 + 重试，保留旧数据 |

**说明**：`empty` 是“查询/数据结果为空”，不是“控件被禁用”；两者视觉必须区分（空态有标题与动作，禁用控件仍有标签）。`error` 只在控件可独立失败时局部展示；快照加载失败一律页面级。

### 6.1 通用状态词典

| 状态 | 视觉 | 行为 |
|---|---|---|
| hover | 背景 `surface-subtle`；链接文字 `accent`；边框 `line-strong → content-muted` | 120ms；不位移、不缩放、不新增阴影 |
| focus-visible | 2px `accent` 外环，offset 2；表格行/单元格用 inset 环，避免被 `overflow-hidden` 裁切 | 键盘可见；鼠标点击不显示 |
| active / pressed | 背景 `surface-sunken` 或 `accent-active`（主按钮） | 不改变尺寸 |
| selected / current | `accent` 文字 + 2px 底边/左边；或 `accent-soft` 底 + `accent-line` 边 | 同一视图只允许一种选中样式 |
| disabled | 45% 透明度 + `cursor-not-allowed`；保留原尺寸 | 不响应 hover；原生 `disabled`；自定义控件加 `aria-disabled` |
| empty | 图标 20 + 标题 16 + 一句原因 + 一个动作 | 不显示空白面板；高度 ≥240 |
| loading | 骨架与最终结构同形；顶部 2px 不确定进度条 | `aria-busy="true"`；禁止重复提交 |
| error | `danger` 图标 + 一句原因 + 重试 | 保留上次成功数据；不整页替换 |

### 6.2 搜索

| 状态 | 触发 | 视觉 | 行为 |
|---|---|---|---|
| idle | 无输入 | 44px 输入框，placeholder `搜索插件、用途或仓库` | 不显示清除按钮 |
| hover | 指针进入 | 边框 `content-muted` | — |
| focus | Tab / 点击 | 边框 `accent` + 3px `accent-soft` 环 | 光标可见；不自动展开筛选 |
| typing | 输入 | 值实时显示；清除按钮出现 | 120ms 防抖；`replace` 更新 `?q=`；`page=1`；结果数 `aria-live` |
| composing | 中文输入法 | 保留输入法候选，不闪烁结果 | `compositionstart` 期间不筛选，`compositionend` 后再更新；避免拼音中间态导致 0 结果 |
| filled | 有值 | 清除按钮 36/44 | 点击清空并聚焦输入框；`Esc` 也清空 |
| no result | 过滤后 0 | 空态替换列表；工具栏保留 | 结果区 `aria-live`：`没有匹配的插件`；焦点留在输入框 |
| long query | 粘贴长文本 | 输入框内滚动，不撑破布局 | 截断到 64 字符；不自动分词 |
| loading | 数据未就绪 | 输入框禁用 + 骨架 | 路由级加载；不出现半可用搜索 |

- 搜索匹配范围保持现有：名称、仓库、描述、语言、许可证、备注、安装命令、分类、topics。
- 不做模糊高亮（会引入 HTML 注入风险）；如需高亮，只对纯文本节点做安全分段。
- 搜索与筛选是 AND 关系；清除搜索不清除筛选，反之亦然；`清除全部` 才全部重置。

### 6.3 筛选

| 状态 | 视觉 | 行为 |
|---|---|---|
| 默认 | select 显示 `全部分类` 等短标签 | 不显示 chips；计数徽章不显示 |
| open | 原生下拉（不做自定义浮层） | 选择即生效；不点“应用” |
| active | select 边框 `accent-line`；下方出现可移除 chip | URL 写入对应参数；`page=1`；结果数播报 |
| 多条件 | chips 横向 wrap；每 chip 可单独移除 | 移除后保留其他条件 |
| 清除全部 | 文字按钮，位于 chips 末尾 | 清空所有筛选与搜索；焦点回到搜索框 |
| 折叠（<1024） | `更多筛选` 按钮 + 数字徽章 | 展开面板；选择后保持展开；`Esc` 收起并回到按钮 |
| 空结果 | 结果区空态 | 不自动重置；提示“清除筛选” |
| 加载 | 筛选器禁用 | `aria-busy`；不显示过期选项 |
| 错误 | 页面级错误 | 不渲染筛选器，避免对空数据操作 |

- 选项计数（P1）：`高风险信号 (3)`，计数基于“排除自身筛选后的结果”，避免出现 0 选项。
- 不做多选；当前数据量（20）不需要。
- 移动端展开面板：单列，每个 select 44px；面板底部固定 `清除全部` + `收起`（两个按钮），不遮住结果首行。

### 6.4 排序

| 状态 | 视觉 | 行为 |
|---|---|---|
| 默认 | `排序：人气`；表头“人气”右侧向下箭头 | 人气降序；空值最后 |
| active desc | 表头文字 `content-primary` + 箭头向下 + `aria-sort="descending"` | 点击同一表头切升序 |
| active asc | 箭头向上 + `aria-sort="ascending"` | 再点切回降序 |
| inactive | 表头 `content-secondary`；箭头在 hover/focus 才出现 | 点击设为该列默认方向（数值降序、名称升序） |
| select 变更 | 下拉显示当前项 | 与表头双向同步；`page=1`；保留筛选 |
| 空值 | `—` 行排在最后，不参与方向反转 | 名称作为稳定第二排序键 |
| 禁用 | 无 | 任何列都可排序；不做“不可排序”的假箭头 |

- 排序字段保持现有 8 个；表头只暴露 4 个高频：人气、维护、覆盖、最近提交；其余通过 select。
- 排序状态写入 URL `sort`；默认 `popularity` 时省略参数。
- 排序变化不改变滚动位置；只播报“已按维护健康度降序排列”。

### 6.5 分页

| 状态 | 视觉 | 行为 |
|---|---|---|
| 默认 | 当前页实心 `accent`；其他文字按钮 | 每页 8 个；`page` 写入 URL，第 1 页省略 |
| 首页/末页 | 上一页/下一页 35% + 禁用 | 原生 `disabled`；不进入 tab 顺序 |
| 省略号 | `…` 非交互 | 只显示 1、当前±1、末页 |
| 越界 | 自动夹到有效页 | 不显示错误页；URL 修正 |
| 翻页 | 页码按钮保持焦点 | 滚动到索引标题；`aria-live` 播报页码与总数 |
| 筛选后 | 自动回第 1 页 | 不保留旧页码 |
| 加载 | 分页禁用 | 骨架行；不显示旧页码 |

- 移动端页码只保留 `上一页 / 下一页` + 上方文字 `第 2 / 3 页 · 共 20 项`；页码列表可省略。
- 不做无限滚动：数据量小、需要可分享页码、且无限滚动会破坏页脚可达性。

### 6.6 图表

| 状态 | 桌面（fine pointer） | 触屏（coarse） | 键盘 / SR |
|---|---|---|---|
| idle | 18 个气泡 + 阈值虚线 + 浅色分区 | 同左 | `role="img"` + `aria-label` + 隐藏数据表 |
| hover | 气泡放大 1.2，tooltip 显示名称/风险/两项分数/stars/下载/覆盖/最后采集 | 不适用 | 不适用 |
| click / tap 1 | 点击气泡进入详情 | 第一次点按：选中 + 显示 tooltip | 通过右侧列表或“列表视图”进入 |
| tap 2 | — | 第二次点按同一气泡：进入详情 | — |
| 分区筛选 | 图与列表同步过滤；轴固定 0–100，不重新缩放 | 同左 | 按钮 `aria-pressed`；列表同步 |
| empty | 不画点；中央说明 + 链接 | 同左 | 同一文案可读 |
| loading | 轴与分区保留，中央“正在读取快照…”；不画假点 | 同左 | `aria-busy` |
| error | 面板内 `InlineNotice` + 重试；不显示半张图 | 同左 | 可读错误文本 |
| tooltip 溢出 | `confine: true`；最大 300px | 同左 | — |
| reduced motion | 动画 0ms | 同左 | — |

- 图表颜色只来自 `chartTheme`；组件内不得写 hex。
- 阈值线用中性虚线；网格线 1px 浅灰；不要用品牌红画阈值（会被误读为风险）。
- 首页图表不显示标签；四象限页 ≥1280 只显示 Top 3 标签，名称截断 14 字符 + `…`。
- 坐标轴固定 0–100；筛选只改变点集，不改变轴范围（现有行为，必须保留）。
- 图表下方必须存在非图表路径：首页 → “完整视图”；四象限 → 侧栏列表；详情 → 数据表/文本。
- P2 可加“列表视图”切换：把当前筛选结果渲染为可排序表格，供键盘与读屏用户使用。

### 6.7 对比入口

| 入口 | 位置 | 行为 | 状态 |
|---|---|---|---|
| 导航 | Header `对比` | 进入 `/compare`（无参数 → 示例对） | 当前路由激活 |
| 详情页 | 页面头 / 右栏 | `加入对比` → `/compare?a={id}`，B 预选“除 A 外人气最高”的插件 | 默认；只有一个插件时禁用 + `title="至少需要两个插件"` |
| 对比页 | A/B select | 选择即更新 URL；同侧不可选另一侧 | 选中项不 disabled；另一侧已选项 disabled |
| 榜单/索引 | 不加入 | 避免每行多一个按钮，保持列表干净 | — |

| 状态 | 处理 |
|---|---|
| 示例对 | 无 `a`/`b`：显示前两个插件 + 一行 12px 说明；不写入 URL（保留可清空状态） |
| 预选 | 详情页只带 `a`：B 自动选一个人气最高且不同的插件；顶部一行 `B 已预选：{name}，可更换。` |
| 相同 | 两项相同：option 禁用；URL 相同则自动修正 B + `InlineNotice` |
| 非法 id | URL 中的 id 不存在：重置为示例 + `InlineNotice` + 地址栏同步 |
| 交换 | 交换 a/b；保留滚动位置；焦点留在交换按钮；播报 |
| 少于 2 个插件 | 整页空态“至少需要两个插件才能比较” |
| 加载 | 选择器禁用 + 两张骨架卡 |
| 错误 | 页面级错误；不渲染半张对比表 |

- 对比入口最多两个（导航 + 详情），不在列表行内重复；这是刻意的“减少干扰”取舍。
- 对比页不提供“保存/分享”按钮；URL 本身就是分享状态。

### 6.8 刷新、加载与错误

| 场景 | 视觉 | 行为 |
|---|---|---|
| 首次加载 | 页面骨架：H1 文案块、四象限框、5 个指标块、6 行榜单、索引工具栏 | 不使用整页 spinner；骨架高度与最终布局一致，避免 CLS |
| 刷新中 | 导航刷新图标旋转；按钮 disabled；顶部 2px 进度条 | `aria-live="polite"` 播报“正在重新加载”；不遮罩内容 |
| 刷新成功 | 时间更新；进度条消失 | 不弹 toast；如数据变化，列表自然更新 |
| 刷新失败（有数据） | 单条 warning 横幅 + `重试` | 保留当前快照；不替换为错误页 |
| 首次加载失败 | `ErrorState`：图标 + 原因 + `重新加载` + 方法链接 | 开发环境显示 `npm run data:pull` 提示；生产不显示 |
| 局部图表错误 | 面板内 notice | 其他区块不受影响 |
| 空数据（加载成功但 0 插件） | 指标为 0/—；图表空态；索引空态 | 不把 0 插件当成错误；提示“快照中没有插件” |

### 6.9 键盘、焦点与播报

- Tab 顺序：skip link → 品牌 → 导航 → 状态胶囊 → 刷新 → 页面主操作 → 内容控件 → 页脚。
- 路由切换：焦点到 `main`（或 H1），`document.title` 更新为 `{页面名} · DSH 插件健康度看板`；滚动到顶部或 hash。
- 搜索/筛选/排序/翻页：焦点留在触发控件；结果数通过 `aria-live="polite"` 播报；不强制把焦点移到结果区。
- 对比交换：播报“已交换 A 和 B”；焦点留在交换按钮。
- 图表：不把 18 个气泡做成 tab 停靠点；提供列表路径；`role="img"` 的 `aria-label` 说明图意，隐藏表格提供数据。
- 弹层/浮层：打开时焦点进入，Esc 关闭，关闭后回到触发器；`InfoHint` 支持点击、Enter/Space、Esc。
- 触摸目标：<768 所有可点元素 ≥44×44；相邻控件间距 ≥8。
- 动效：`prefers-reduced-motion` 下取消页面淡入、图表动画、平滑滚动。

### 7.5 横向溢出规避

**验收方法**：在 390/768/1440 下执行

```js
document.documentElement.scrollWidth <= window.innerWidth
```

必须为 true；若为 false，按以下顺序排查：

1. **表格**：≥1024 使用 `table-fixed` + `colgroup`；最后一列固定 48px。1024 以下不使用表格（卡片/堆叠卡）。
2. **方法页宽表**：<768 转为卡片；≥768 表格最小宽 680/720，外层 `overflow-x-auto` + `role="region"` + `tabIndex=0` + 淡出边缘；页面本身不滚。
3. **详情解释表**：<768 转为定义列表卡；≥768 表格 `min-w-[640px]`，外层滚动容器。
4. **图表**：容器 `w-full`，无 `min-width`；ECharts `resize`；tooltip `confine`。
5. **长串**：URL/安装命令 `break-all`；中文 `break-words`；flex 子项 `min-w-0`。
6. **100vw**：禁止使用；需要全宽时用 `w-full` + 容器内边距。
7. **负边距**：只在有等量内边距补偿时使用；移动端避免 `-mx-4` 导致 8px 溢出。
8. **原生 select**：`max-width: 100%`；长 option 由浏览器截断，不撑破容器。
9. **移动菜单**：`max-height: calc(100dvh - 56px)` + `overflow-y-auto`；不横向滚动。
10. **sticky + 锚点**：统一 offset 变量；避免固定 `top-16` 在横幅出现时错位。

## 8. 内容层级与中文可读性

### 8.1 层级

- 每页一个 H1；每个区块一个 H2；面板/列表一个 H3；不出现 H4。
- eyebrow 是 `<p>` 不是标题；不参与大纲。
- 视觉层级：H1 > 区块 H2 > 数据主角（图/表/分值） > 面板 H3 > 行名称 > 说明。
- 同一屏不超过 3 种字号层级；12px 只做标签，不做句子。

### 8.2 字号 / 行高 / 字重

| 角色 | 390 | 768 | 1440 | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|---|
| H1 | 32 | 40 | 48 | 600 | 1.15 / 1.1 | 每页唯一 |
| H2 | 22 | 24 | 24 | 600 | 1.3 | 区块 |
| H3 | 16 | 18 | 18 | 600 | 1.4 | 面板/列表 |
| lead | 15 | 16 | 16 | 400 | 1.75 | 页面说明，≤2 行 |
| body | 14 | 15 | 15 | 400 | 1.65 | 正文 |
| small | 13 | 13 | 13 | 400 | 1.55 | 辅助说明 |
| caption | 12 | 12 | 12 | 500 | 1.5 | 标签/元信息 |
| 大数字 | 32 | 36 | 40 | 600 | 1 | 指标/评分 |
| 表头 | 12 | 12 | 12 | 500 | 1.4 | 表格 |
| 按钮 | 14 | 14 | 14 | 500 | 1.2 | 操作 |

- 中文行高不低于 1.6；标题 1.1–1.3。
- 中文字距 0；`0.04em` 只用于拉丁 eyebrow/编号。
- 不使用 300 字重；浅色底上 400 已足够。
- 正文最大宽度 34em（约 34 个汉字）；方法页 34em；列表说明 28em。

### 8.3 文案规则

1. **一句一事**，单句 ≤45 个汉字；移动端段落 ≤3 行。
2. **动作前置**：`浏览全部插件`、`加入对比`、`查看方法`；不用“点击这里”。
3. **限定词固定**：`相对`、`公开信号`、`可能`、`不等于`；不省略。
4. **禁用词**：`安全`、`最佳`、`推荐`、`权威`、`零风险`、`保证`。
5. **术语统一**：
   - 插件（不是“项目/扩展”）
   - 人气指数 / 维护健康度（不混用“热度/维护分”）
   - 数据覆盖 / 数据完整度（`5/7 域` 与 `71%` 同时出现时，前者是覆盖域数，后者是百分比）
   - 公开风险信号（不是“漏洞结论”）
   - 快照（不是“缓存/数据包”）
6. **数字与单位**：`20 个插件`、`3 条信号`、`2.6M 次`、`21 次 / 30d`、`0–100`；数字与中文之间留空格。
7. **标点**：中文全角；元信息分隔用 `·`；比值用 `/`；不用 `｜` 和连续感叹号。
8. **错误文案**：发生什么 + 现在展示什么 + 下一步；不指责用户。
9. **空态文案**：不写“暂无数据”四个字了事；必须解释原因与下一步。
10. **免责声明**：只保留方法条与方法页的完整版本；页脚一句；详情页边界卡一段；不在每个区块重复。

### 8.4 数字格式

- 指数：1 位小数（`67.9`）；风险条数：整数；覆盖率：整数；比率：1 位小数（`94.7%`）。
- 大数：`formatCompact`（`43.2k`、`2.6M`），`title` 给精确值；同一屏内保持同一精度。
- 负数/差值：`+3.2` / `−5.1`（使用真正的减号或 ASCII `-` 统一一种）；对比页固定 `B − A`。
- 时间：相对时间用于导航与列表；绝对时间用于数据面（`2026-10-20 11:25`）；`title` 给完整时间。
- 缺失：`—`（em dash），不用 `N/A`、`null`、`0`。
- 等宽数字：所有分数、计数、时间、百分比使用 `tabular-nums`；不要给整段中文加 mono。

| `PluginExplorer` | 首页索引 | 唯一搜索/筛选/排序/分页入口；URL 状态；表格/卡片 | 不要在别处再做一套筛选 |
| `QuadrantChart` | 首页、四象限页 | 固定 0–100；阈值中性；Top3 标签仅 ≥1280；`chartTheme` | 不要重设轴范围；不要用品牌红画阈值 |
| `ScoreTrendChart` | 详情 | 真实历史点；不足不画；固定 0–100 | 不要插值/补点；不要假数据 |
| `DownloadBars` | 详情 | 30 天日数据；缺数日灰块；7 日均线 | 不要把缺数当 0；不要用 Star 冒充下载 |
| `ScoreBar` | 榜单、评分、卡片 | 4–6px 高；只表示分数；颜色用 accent/中性 | 不要用于覆盖率（用分段） |
| `RiskBadge` | 列表、详情、对比 | 图标 + 文字；compact 用于表格 | 不要只给颜色；不要写“安全” |
| `DataCoverage` | 索引、对比、详情 | 7 段 + `n/7`；可附 `%` | 不要只给百分比不给域数 |
| `CoverageChip` | 详情/对比 | `5/7 数据域`；title 给百分比 | 不要用于风险 |
| `InfoHint` | 口径、阈值、字段说明 | 每格最多 1 个；点击/键盘可开；宽 240 | 不要放长段落；不要用于关键结论 |
| `Pagination` | 索引 | 固定 8/页；URL；焦点与播报 | 不要无限滚动；不要每页数量选择器 |
| `EmptyState` | 索引、图表、对比、详情 | 标题 + 原因 + 一个动作；≥240 高 | 不要插画；不要空白 |
| `InlineNotice` | 局部降级/缺口 | 每区块最多 1 条；3 种语义 | 不要用于营销/提示技巧 |
| `CopyButton` | 详情安装命令 | 复制成功 1.6s 反馈；失败提示 | 不要自动复制；不要隐藏命令 |
| `ButtonLink/Anchor` | 页面头、空态、对比 | 主按钮 1 个；次要 ≤2；其余文字链接；40/44 | 不要 3 个同权重按钮 |
| `PluginMonogram` | 列表/详情 | 2 字符；装饰 `aria-hidden` | 不要伪装成真实头像 |
| `CategoryTag` | 列表/详情 | 12px；中性底；圆点 4px | 不要用分类颜色编码风险 |
| `ExternalTextLink` | 证据/来源 | 外链图标；`noopener`；hover 下划线 | 不要在正文中大量堆叠 |

### 9.3 禁止项

- 禁止在 TSX 中新增 hex / rgb；颜色只通过语义 token 或 `chartTheme`。
- 禁止继续使用 `ink-*` 兼容别名写新组件；统一 `canvas/surface/line/content/*`。
- 禁止 `rounded-lg` 以上的面板圆角、重阴影、玻璃拟态、渐变卡片。
- 禁止用品牌红做风险徽章底色、表格斑马纹、图表阈值线。
- 禁止只用颜色表达风险、状态、选中；必须配文字/图标/线型。
- 禁止用 12px 以下字号承载正文或关键状态；禁止用透明度低于 4.5:1 的文字。
- 禁止在图表中补造数据点、用 0 代替缺失、用假趋势占位。
- 禁止同一屏两个主按钮；禁止把 5 个区块都做成同尺寸卡片。
- 禁止把方法声明散落到每个区块；禁止在页脚重复完整免责声明。
- 禁止隐藏核心信息（时间、来源、缺失原因）只在 tooltip 中可见。
