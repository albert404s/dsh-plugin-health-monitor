# 03 · Lead 决策记录（实现约束）

> 本文件用于消解 `01-visual-system.md` 与 `02-ux-layout.md` 的分歧；三者冲突时以本文件为准。基线 `785c8f2`，分支 `ui/light-tech-redesign`。

## 1. 令牌与视觉

1. 颜色/字体/圆角/阴影的唯一来源是 `01-visual-system.md` §1.2 与 §2.1；品牌红 `#D71920`。保留旧类名兼容别名，避免大面积改名导致回归。
2. 红色只用于交互、当前项、品牌刻度；数据、排行榜条、分类点、风险标签不得使用品牌红。
3. 风险四级使用 01 的锈红/琥珀/钢蓝/中性，并同时带图标与中文文字；不得只靠颜色。
4. 点阵标题采用 01 §3.5 的 CSS 半调点阵 + `background-clip:text`，不引入外网字体；不支持时回退实心墨色，`forced-colors` 下回退。
5. 图表全部颜色收口到 `chartTheme.ts`，组件内不得再写 hex；浅底对比度按 01 §7。

## 2. 首屏与主视觉

1. 首屏按 `02` §3.2：桌面 5/7 双栏，左文案右四象限面板，图高 440（1440）/420（1024）/380（768）/300（390）。
2. 主视觉放置（消解 01 §5.5 与 02 的冲突）：**不占用四象限的右栏**。
   - ≥1024：银色模块插画置于左栏 CTA/文字链接**下方**，宽 240–300px，左对齐，配可见图注「装饰示意，不表示数据」；不得覆盖文字、按钮、图表，不得把图表挤出首屏。
   - 768：不放大图，仅在 eyebrow 行使用 112px 的 CSS 模块标记。
   - 390：使用 96px CSS 模块标记，与 eyebrow 同行或紧邻标题上方，不遮文字。
   - 插画用内联 SVG + CSS 实现（参考 01 §5.3/§5.4，可适度简化，≤8KB），`aria-hidden`、`pointer-events:none`，无持续动画，不引入 3D 库。
3. 删除首屏 meta 行（更新时间/插件数/高风险/来源降级）；更新时间由 Header 相对时间承担，绝对快照由指标带出处行承担。
4. 首屏只保留一个实心按钮「浏览全部插件」；「四象限完整视图」「评分方法」为文字链接。

## 3. 导航与首页结构

1. 导航 5 项：总览 / 四象限 / 插件索引 / 对比（文案可保留“插件对比”）/ 方法。移动端汉堡菜单保留，GitHub 入口保留。
2. 「插件索引」指向 `/#all-plugins`：需要实现 hash 滚动（考虑 sticky header 偏移）与目标聚焦；不得新增无数据页面。
3. 首页顺序：Header →（异常时 DataNotices）→ 首屏+四象限 → 仪器指标带 → 榜单+关注/变化 → 插件索引 → 计算说明条 → Footer。
4. 列表/榜单/指标的去重与文案删减按 `02` §3.7；每个区块只保留一个视觉主角。
5. 指标带 5 格：已核验插件 / 总 Stars / npm 30 天下载 / 高风险 / 数据完整；底部加 32px 数据出处行（绝对快照 + 三来源状态）。高风险格可点击筛选，若现有 URL 参数不支持则先链接到 `/#all-plugins`，不得做假交互。
6. 榜单在 ≥1280 为 8+4（榜单 + 关注/变化），1024–1279 为 6+6，<1024 单列；移动端关注 4 条、变化 3 条。

## 4. 其余页面与交互

1. 插件详情：≥1280 启用右栏（目录/快照/对比入口），<1280 目录折叠到顶部；保留现有解释表、来源表、趋势与下载图。
2. 对比页：保留现有 A/B、预选、交换、矩阵与 sticky 表头；表头偏移改用 `--header-h`，与 64px Header 对齐（e2e 断言 63–66px）。
3. 方法页：<768 宽表转卡片，避免横向滚动；保留全部公式、口径、来源。
4. 四象限页：保留固定 0–100 轴、筛选、点击；本期不把筛选写入 URL（P2 延后）。
5. 筛选 option 计数（P1）本期不做；移动端每页数量维持 8，不改分页语义。
6. 所有交互态补齐：hover / focus-visible / active / disabled / empty / loading / error；路由切换更新 `document.title` 并将焦点移到 `main`。
7. 空态、缺失值、风险、时效提示就近呈现；`—` 必须带原因，不得渲染为 0。

## 5. 功能与数据红线

1. 不修改评分逻辑、数据文件、采集脚本；趋势图必须来自 `history.json`/`snapshots` 真实同口径历史。
2. 保留搜索、筛选、排序、分页、图表点击、对比、URL 状态、刷新与失败保留旧快照等现有行为。
3. 不新增 npm 依赖；不引入外网字体/图片；不伪造任何数字或“示例数据”。
4. 装饰（刻度、点阵、编号、扫描线、插画）不得带单位、百分比、时间或 tooltip，不能与真实读数混淆。

## 6. 验收

1. `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` 全绿；e2e 若因有意的结构调整需更新，必须保留原有语义断言，不得放宽为“存在即可”。
2. 390 / 768 / 1440 无页面级横向滚动；1440 下首屏能看到四象限图主体。
3. 实际浏览器截图：首页三档 + 四象限/详情/对比/方法至少各一档；由 Evidence Collector 执行。
4. 本轮不 commit / push / PR / 部署 / tag。
