# 手动采集控制

网站仅支持维护者手动采集。工作流已删除定时触发，控制层也拒绝旧的定时请求；默认自动采集关闭。

| 动作 | 作用 | 调用数据API |
|---|---|---|
| refresh | 保存目标与预算，采集一次并发布 | 是 |
| configure | 只保存下次手动采集的设置 | 否 |
| pause | 兼容旧链接，记录自动采集关闭 | 否 |
| resume | 不再开放；旧请求也保持关闭 | 否 |

操作入口为网站右上角“数据更新”。前往GitHub，Run workflow选main和refresh，照页面表格填写target_plugins、max_plugins、max_requests、github_reserve。完成后返回网站刷新已发布数据。

网页每60秒读取快照只用于展示同步，不会启动采集。暂停或关闭定时不会取消已经开始的任务；若有旧定时任务需单独核对。

收录目标、实际记录、每轮上限、预算及缓存说明见 [数量与更新](CATALOG-AND-LIVE-COUNTS.md)。网页不保存访问令牌，采集需要仓库写入权限。
