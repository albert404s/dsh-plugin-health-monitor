# ORBIT 本地交付说明

本地改造起点为团队主分支 `41b6908`。前端位于 `codex/orbit-frontend`；数据质量工作在其后续独立分支 `codex/data-quality` 中实现。本轮不推送、不创建 PR、不合并团队主分支。旧版分支 `backup/before-update-20261020-006b420` 继续保留。

## 使用

在项目目录执行 `npm run dev -- --host 127.0.0.1 --port 5173`，访问 http://127.0.0.1:5173/ 。父目录的“启动项目.cmd”也可启动。

导航为概览、插件库、生态分布、插件对比、数据与方法。插件库勾选最多两个插件后，底部浮出对比入口。搜索、筛选、排序和分页存入网址；旧首页检索链接与 /quadrant 会保留参数跳转。生态分布可以通过鼠标点图，也可通过键盘选择右侧列表，阅读摘要后进入详情。

“关注度”描述样本内相对位置，“维护活跃度”描述公开维护活动，“数据完整度”描述取得的数据域。关注事项分为维护提醒、公开漏洞与数据缺口。评分方法仍为 1.1.0；方法版本、参与分项、有效权重或采集时间不同，停止计算分差。原始指标依然可查。

## 动效与性能

轨道装置是装饰示意。Three.js 在桌面且允许动态效果时延迟加载；减少动态效果、移动端、省流或 WebGL 不可用时保留 SVG。离屏与后台暂停，卸载释放 WebGL 资源。真实插件数据采用二维 ECharts，配有文字列表与读屏表格。

最终生产构建中，必要 JS/CSS gzip 为 约 345 KB；3D 独立文件约 136 KB，不计入必要首屏。验收使用 Chromium 覆盖 390、768、1024、1366、1440、1920 px，关键桌面高度为 768、900、1080 px。截图保存在项目父目录的“ORBIT-验收”文件夹。

## 开发检查

- `npm run typecheck`
- `npm test`
- `npm run test:e2e`（本机需设置 PLAYWRIGHT_BROWSERS_PATH 指向父目录 .playwright-browsers）
- `npm run build`
- `npm run check:dist`

仓库没有 lint 命令，类型检查与构建承担静态检查。实际数据文件、构建产物和临时验收脚本保持忽略。

## 精简与动效调整

删除首页长介绍、侧栏副文案和标题下重复解释；必要说明改为可悬停、聚焦或轻触查看的提示。顶栏仅显示当前页面，移除“工作台”面包屑。页面与导航采用轻量回弹和按压反馈。轨道装置改为带光晕、刻度和卫星的环仪，不再显示说明文字。

生态图只对装饰光晕作低频脉动，数据点位置和值保持固定。鼠标距图表 56px 内或键盘焦点进入图表区域时暂停，移开后继续；离屏、后台暂停，减少动态效果时关闭。27 项浏览器测试包含提示的键盘访问和靠近后暂停验证。最终六档尺寸无横向溢出，生产控制台错误为 0。本轮只修改本地，推送和部署继续暂停。
